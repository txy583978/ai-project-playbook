# AI Project Playbook | AI全栈项目开发实战手册

一套从需求分析到部署上线的完整AI辅助项目开发模板，配合AI写代码，让你从0到1做出专业级项目。

## 这是什么？

这是一套**教练式AI提示词模板集**，把全栈项目开发拆成11个步骤，每一步都有专门的模板引导你：
- 该问什么问题
- 该输出什么结果
- 常见错误是什么
- AI该怎么帮你做

适合：学生做毕设、转行者做简历项目、个人开发者做MVP、小团队协作。

---

## 先看这里：你是哪种用户？

这套模板有**两种用法**，根据你的目标选一条走：

### 🎓 学生版：课程作业 / 毕设（快速跑通就行）

**目标：** 做出一个能跑的项目，交作业拿分。不用追求工业级标准。

**必须做的步骤：**
| 步骤 | 做什么 | 做到什么程度就行 |
|---|---|---|
| 0 | 调研 | 找2-3个竞品，列优缺点 |
| 1 | 需求分析 | 确定MVP做哪1件事 |
| 2 | 数据库设计 | 设计表结构，不用追索引/软删除 |
| 3 | 接口设计 | 设计5个左右接口 |
| 4 | 前端设计 | 设计3-4个页面 |
| 5 | 项目结构 | 建好目录，跑起来 |
| 6 | 项目记忆文件 | 生成AGENTS.md和MEMORY.md |
| 7 | 写代码跑通 | 本地能跑、能登录、能增删改查 |
| 8 | 代码审查 | 让AI帮你查一遍bug，改了就行 |

**可以跳过的步骤：**
- ❌ 第9步测试：不用追70%覆盖率、不用配CI。写3-5个核心接口的测试用例就行。
- ❌ 第10步部署：不用自己买服务器配Nginx。本地跑通就交作业，想演示的话用校园网/内网穿透给老师看。

---

### 🚀 完整版：上线产品 / 简历项目（工业级标准）

**目标：** 做一个真的有人用的产品，或者写在简历上能经得起面试官问的项目。

**全部11步都要做：**
从0到10一步不落，按模板里的工业级标准来——测试覆盖率70%+、CI自动跑、Nginx+HTTPS、数据库备份、回滚方案，全套配齐。

## 怎么用这套模板

### 使用流程：一步一步走，走完一步发交接卡

1. **先打开第0步模板**，复制给AI → AI当教练引导你做调研
2. **走完第0步**，AI输出交接卡 → 你把交接卡复制下来
3. **打开第1步模板**，连同交接卡一起发给AI → AI接着带你做需求分析
4. **第1步选完技术栈**（比如FastAPI），从第2步开始：
   - 每发一步模板，都要把**对应的技术栈插件**一起发给AI
   - 一直带到第10步结束
5. **走到第6步**，AI帮你生成`AGENTS.md`——以后新开对话，直接把AGENTS.md发给AI就行，不用从头走
6. **走完第10步**，项目就完成了

> 💡 **为什么要每一步都带插件？**
> 第2步设计数据库要知道"金额用DECIMAL不用FLOAT"，第3步设计接口要知道"统一返回格式"，第8步审查要对照"反模式清单"——这些规则全在插件里。
> 只在写代码时才加载插件，前面设计的东西就会和后面生成的代码对不上。

## 怎么用？

第一次使用：
1. 复制 0调研模板.md 的全部内容
2. 粘贴给 AI（ChatGPT / Claude / 豆包都行）
3. 它会问你第一个问题，你回答就行
4. 它判断你答得对不对，不合格会让你重答
5. 走完调研，再复制 1需求分析教练 继续

整体流程：
1. 按顺序从0到10，一步一步来
2. 每一步把对应模板复制给AI，让它像教练一样带你走
3. 写代码时，把附录A和项目记忆文件一起给AI
4. 做完一步，确认合格了再进下一步

## 设计理念：两类坑，两种覆盖方式

做项目踩的坑分两层，模板用不同机制分别覆盖，不要混为一谈：

### 第一类：普通边界问题（已知的未知）

**定义：** 你知道有这个场景存在，只是设计的时候忘了考虑它。

比如：用户上传空文件怎么办？知识库里没文件就提问怎么办？参数传空怎么办？这些场景你意识范围内有，只是漏了。

**覆盖方式：** 第1步需求分析、第2步数据库设计、第3步接口设计的模板里，都有强制的"异常点清单"，分业务类、技术类、用户类三类，设计阶段主动一个个确认，不许只做理想流程。

### 第二类：隐性暗坑（未知的未知）

**定义：** 你连这个东西存在都不知道，没人告诉你就会踩，更别说提前考虑了。

比如：中文 RAG 场景下 embedding 模型分中英文，默认英文模型检索会退化成关键词匹配；命令行程序不走 Windows 系统代理；换 embedding 模型必须重建向量库。你连"embedding 模型有语种之分"这个概念都没有，设计时根本想不起来要选模型。

**覆盖方式（两道防线）：**
1. **技术栈插件的常见坑清单**：把踩过的专家经验提前列在插件里，AI 设计和写代码时主动提醒。
2. **第7步开工前先扫坑**：模板里预先列的坑不可能覆盖全世界所有经验。第7步写代码之前，AI 必须主动搜索该技术栈 + 该场景的官方最佳实践和开发者踩坑记录，列成清单告诉用户，再动手写代码。

## 核心特点

- **全流程覆盖**：从调研到部署，不跳步
- **教练式引导**：不是给AI指令，是引导你想清楚
- **AI行为约束**：避免AI过度设计、硬编码、分层混乱
- **开工前主动扫坑**：写代码前先搜该技术栈和场景的最佳实践与常见暗坑，不靠人工列全所有经验
- **专业标准**：HTTP状态码规范、安全越权、测试分层、部署专业项
- **通用示例**：用products示例，不绑定具体项目
- **项目交接卡**：每步走完输出交接卡，跨会话不中断，不用从头再说一遍
- **多栈支持**：通用原则 + FastAPI/Django/Spring Boot示例，不是FastAPI专属
