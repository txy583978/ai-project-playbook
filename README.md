# AI Project Playbook | AI全栈项目开发实战手册

一套从需求分析到部署上线的完整AI辅助项目开发模板，配合AI写代码，让你从0到1做出专业级项目。

## 这是什么？

这是一套**教练式AI提示词模板集**，把全栈项目开发拆成10个步骤，每一步都有专门的模板引导你：
- 该问什么问题
- 该输出什么结果
- 常见错误是什么
- AI该怎么帮你做

适合：学生做毕设、转行者做简历项目、个人开发者做MVP、小团队协作。

## 目录结构

| 序号 | 模板 | 解决什么问题 |
|---|---|---|
| 0 | 调研模板 | 找竞品、列优缺点，避免闭门造车 |
| 1 | 需求分析教练 | 从想法到MVP，确定用户、痛点、功能范围 |
| 2 | 数据库设计模板 | 设计表结构、索引、约束、软删除 |
| 3 | 接口设计模板 | RESTful接口、统一响应、分页、鉴权 |
| 4 | 前端页面设计模板 | 页面结构、组件、前后端联调 |
| 5 | 项目结构分层模板 | 目录分层、.gitignore、配置分离 |
| 6 | 项目记忆文件模板 | 给AI的项目上下文，避免每次重复说 |
| 7 | 代码审查模板 | 安全、越权、事务、分层、硬编码 |
| 8 | 测试模板 | 单元测试、集成测试、CI自动化 |
| 9 | 部署模板 | 服务器部署、上线检查、回滚方案 |
| 附录A | AI提问约束模板 | 通用约束 + 技术约束，让AI不乱写 |

## 怎么用？

第一次使用：
1. 复制 0调研模板.md 的全部内容
2. 粘贴给 AI（ChatGPT / Claude / 豆包都行）
3. 它会问你第一个问题，你回答就行
4. 它判断你答得对不对，不合格会让你重答
5. 走完调研，再复制 1需求分析教练 继续

整体流程：
1. 按顺序从0到9，一步一步来
2. 每一步把对应模板复制给AI，让它像教练一样带你走
3. 写代码时，把附录A和项目记忆文件一起给AI
4. 做完一步，确认合格了再进下一步


## 核心特点

- **全流程覆盖**：从调研到部署，不跳步
- **教练式引导**：不是给AI指令，是引导你想清楚
- **AI行为约束**：避免AI过度设计、硬编码、分层混乱
- **专业标准**：HTTP状态码规范、安全越权、测试分层、部署专业项
- **通用示例**：用products示例，不绑定具体项目
- **项目交接卡**：每步走完输出交接卡，跨会话不中断，不用从头再说一遍
- **多栈支持**：通用原则 + FastAPI/Django/Spring Boot示例，不是FastAPI专属

## 技术栈示例

正文是通用原则，每个模板末尾有技术栈特定示例：
- Python栈：FastAPI / Django
- Java栈：Spring Boot
- Node栈：Express
- 数据库：MySQL / PostgreSQL
- 部署：Nginx + Ubuntu
